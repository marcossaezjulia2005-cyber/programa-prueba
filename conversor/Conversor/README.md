# Conversor de Unidades de Longitud

Una aplicación gráfica simple e intuitiva desarrollada en Python con Tkinter para realizar conversiones entre distintas unidades de longitud.

## Características

- Conversión rápida entre:
  - **Milímetros (mm)**
  - **Centímetros (cm)**
  - **Metros (m)**
- Interfaz gráfica limpia y amigable construida con `tkinter`.
- Validación de entradas numéricas con cuadros de diálogo de advertencia/error.
- Botón de limpieza para reiniciar los campos fácilmente.

## Requisitos

- Python 3.x
- Tkinter (incluido por defecto en la mayoría de instalaciones de Python en Windows/macOS).

## Ejecución

Para iniciar la aplicación, abre una terminal en esta carpeta y ejecuta:

```bash
python conversor.py
```
